How it works

The account owner prepares the image, Pin title, description, alt text and destination board. The publisher sends the day's two entries to the official Pinterest API when the daily schedule runs. It records successful Pin IDs and stops for review when a result is uncertain, helping avoid duplicate posts.

API authorization is limited to the owner's account. This is not a service for other Pinterest users, an advertising manager, or a tool for collecting other people's Pins.

Account and data

The publishing queue and API credentials are held on the operator's computer. Publishing sends the selected content to Pinterest. The app does not request Pinterest passwords.
